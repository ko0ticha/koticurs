# 📚 Платформа онлайн-курсов (1:1 Реплика)

Полнофункциональная платформа для онлайн-курсов с интерфейсом 1:1 как на [kursegeoge.com](https://kursegeoge.com/course?c=fiz#lesson-0).

---

## 🚀 Быстрый запуск

### Вариант 1: Локально
```bash
python3 -m http.server 8000
```
После этого откройте: **[http://localhost:8000](http://localhost:8000)**

### Вариант 2: Деплой на GitHub Pages
1. Создайте репозиторий на GitHub и загрузите файлы проекта:
   ```bash
   git init
   git add .
   git commit -m "Initial course platform commit"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```
2. В репозитории на GitHub перейдите в **Settings** → **Pages** → **Source**: выберите ветку `main` и нажмите **Save**.
3. Сайт мгновенно станет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` (все файлы `.nojekyll`, `404.html` и относительные пути уже настроены!).

## 🎯 Что реализовано

1. **Курс — Egeland обществознание // ЕГЭ 2026 (Сентябрь)**:
   - **14 полноценных уроков** (Уроки 1–12 + бонусные уроки).
   - **Все 103 PDF-файла** (скрипты, конспекты, скелеты, чек-листы, ДЗ, тесты, ответы).
   - **Видео встроены напрямую** через чистые плееры Kinescope и Rickege.
   - **Интерактивные таймкоды и темы**: под видео отображается список тем и глав с точным временем (`02:40`, `16:05` и т.д.). Клик по любой теме мгновенно перематывает видео на нужный момент!
2. **Вкладка «Расписание»**:
   - Расписание вынесено из списка уроков в отдельную кнопку в левом меню сайдбара (**«Расписание»**).
   - По клику открывается красивое модальное окно с расписанием, зумом и кнопкой скачивания.
3. **Функционал 1:1**:
   - Тёмная и светлая темы (сохраняются в `localStorage`).
   - Сворачиваемый компактный сайдбар на десктопе и бургер-меню на смартфонах.
   - Поиск по урокам и курсам.
   - Переключатель месяцев в правом сайдбаре (Сентябрь, Октябрь, Ноябрь).
   - Анимированная кнопка лайка с локальным счётчиком.
   - Переключатель частей видео (если в уроке более одного видео).

## 📂 Структура проекта

```text
koticurs/
├── index.html                   # Главная страница курса
├── course.html                  # Альтернативная точка входа
├── css/
│   └── style.css                # 1:1 стили, Manrope, тёмная/светлая тема, таймкоды
├── js/
│   └── app.js                   # Логика: плеер, таймкоды, перемотка, расписание
├── data/
│   ├── courses.json             # Реестр курсов и месяцев
│   └── courses/
│       └── egeland/
│           └── months/
│               └── 09-september/
│                   └── lessons.json   # Уроки, видео с главами, таймкоды и файлы
├── files/
│   └── egeland/
│       ├── 09-september/        # Все 103 PDF-файла материалов и ДЗ
│       └── photos/              # Фото расписания
└── tools/
    ├── add_month.py             # Скрипт создания нового месяца
    └── add_lesson.py            # Скрипт добавления нового урока
```

---

## 📝 Как добавлять новые месяцы и уроки

### Создание нового месяца
```bash
python3 tools/add_month.py --id 10-october --title "Октябрь 2026 г."
```

### Добавление нового урока
```bash
python3 tools/add_lesson.py
```
*(Скрипт интерактивно запросит номер, название, ссылку на видео и файлы).*
