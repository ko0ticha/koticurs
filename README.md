# 📚 Платформа онлайн-курсов (1:1 Реплика)

Полнофункциональная платформа для онлайн-курсов с интерфейсом 1:1 как на [kursegeoge.com](https://kursegeoge.com/course?c=fiz#lesson-0).

---

## 🚀 Быстрый запуск

Для корректной загрузки данных уроков и предотвращения ограничений CORS браузера запустите локальный сервер из этой папки:

```bash
# В терминале в папке проекта:
python3 -m http.server 8000
```

После этого откройте в браузере:
👉 **[http://localhost:8000](http://localhost:8000)**

## 📖 Инструкция: Как добавлять новые месяцы

### Способ 1. Через скрипт (рекомендуется)
Запустите в терминале:
```bash
python3 tools/add_month.py
```
Скрипт интерактивно спросит курс, ID месяца и название, создаст папку для файлов и зарегистрирует месяц в `data/courses.json`.

Либо одной командой с параметрами:
```bash
python3 tools/add_month.py --course egeland --id 10-october --title "Октябрь 2026 г." --short "Октябрь"
```

### Способ 2. Вручную
1. Создайте папку для данных: `data/courses/egeland/months/10-october/`
2. Создайте пустой файл уроков: `data/courses/egeland/months/10-october/lessons.json` с содержимым `[]`
3. Создайте папку для файлов: `files/egeland/10-october/`
4. В файле `data/courses.json` в массив `"months"` добавьте объект:
```json
{
  "id": "10-october",
  "title": "Октябрь 2026 г.",
  "shortTitle": "Октябрь",
  "dataPath": "data/courses/egeland/months/10-october/lessons.json"
}
```

## 📝 Инструкция: Как добавлять новые уроки

### Способ 1. Через скрипт (рекомендуется)
Запустите:
```bash
python3 tools/add_lesson.py
```
Скрипт в диалоговом режиме спросит:
- Курс и месяц
- Номер урока и название
- Ссылку на видео (YouTube, Kinescope, Rutube, embed или ссылка на плеер)
- Названия и пути к файлам материалов и домашнего задания.

Либо с параметрами:
```bash
python3 tools/add_lesson.py \
  --course egeland \
  --month 10-october \
  --num "13" \
  --name "Урок 13. Правовое регулирование общественных отношений" \
  --video "https://kinescope.io/embed/XXXXX"
```

---

### Способ 2. Напрямую через JSON
Откройте нужный `lessons.json` (например, `data/courses/egeland/months/09-september/lessons.json`) и добавьте новый объект урока в массив:

```json
{
  "num": "13",
  "date": "15 октября",
  "name": "Урок 13. Правовое регулирование",
  "videos": [
    {
      "label": "Видео урока",
      "url": "https://watch.school-such.site/egeland/XXXXX"
    }
  ],
  "materials": [
    {
      "label": "Скрипт к уроку 13.pdf",
      "url": "files/egeland/10-october/script_13.pdf",
      "type": "lesson"
    },
    {
      "label": "Конспект к уроку 13.pdf",
      "url": "files/egeland/10-october/notes_13.pdf",
      "type": "lesson"
    }
  ],
  "homework": [
    {
      "label": "ДЗ к уроку 13.pdf",
      "url": "files/egeland/10-october/hw_13.pdf",
      "type": "homework"
    },
    {
      "label": "Ответы к ДЗ 13.pdf",
      "url": "files/egeland/10-october/answers_13.pdf",
      "type": "answer"
    }
  ],
  "links": [
    {
      "label": "Интерактивный квиз по терминологии",
      "url": "https://quizlet.com/..."
    }
  ],
  "quiz": null
}
```

#### Какие видео поддерживаются:
- **Kinescope**: ссылки вида `https://kinescope.io/XXXXX` или `https://kinescope.io/embed/XXXXX`.
- **YouTube**: `https://youtube.com/watch?v=...`, `https://youtu.be/...` или `https://www.youtube.com/embed/...`.
- **Rutube**: `https://rutube.ru/video/...` или `https://rutube.ru/play/embed/...`.
- **Внешние плееры**: `https://watch.school-such.site/...`, `https://rickege.com/watch/...` и любые другие iframe-совместимые плееры.

#### Добавление интерактивного автотеста (Quiz):
Вместо `"quiz": null` можно указать автотест с проверкой ответов и формулами:
```json
"quiz": {
  "title": "Автотест к уроку 13",
  "questions": [
    {
      "id": "q1",
      "type": "single",
      "question": "Что из перечисленного является нормой права?",
      "options": [
        "Правило этикета",
        "Закон РФ",
        "Традиция семьи"
      ],
      "answer": "2",
      "explanation": "Норма права устанавливается и охраняется государством."
    },
    {
      "id": "q2",
      "type": "text",
      "question": "Вставьте пропущенное слово: высшей юридической силой в РФ обладает ...",
      "answer": "конституция",
      "explanation": "Конституция Российской Федерации имеет высшую юридическую силу."
    }
  ]
}
```
Фронтенд автоматически отрисует формулы KaTeX (если в тексте есть `$$...$$` или `$..$`), проверит ответы, подсчитает процент и покажет разбор ошибок.
